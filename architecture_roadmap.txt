================================================================================
0. 一句话定位
================================================================================

目标不是“数论 RAG 聊天机器人”，而是：
  AI Number Theorist workspace
  —— 以 LLM 为编排层，以数学检索 + Sage/PARI 计算 + Lean 形式验证为能力核心。

正确性承诺应改为：分级可信度（V0–V4）与门控；达不到门槛时诚实说不确定。


================================================================================
1. 正确总体结构（目标架构）
================================================================================

用户界面（Chat / Notebook）
        |
        v
单一强 Agent（LLM + 受控工作流 + tool calling）
  - 意图识别：teach / solve / research / formalize
  - 检索规划与数学 query expansion
  - 候选答案与证明计划
  - 工具调用与结果回灌
  - 批判检查与正确性门控
        |
        +------------------+------------------+
        |                  |                  |
        v                  v                  v
 Mathematical RAG      Math Tools        Research Tools
 教材/讲义/定理库       SageMath           arXiv
 笔记/本地语料          PARI/GP            OEIS
 日后 papers            Lean 4+mathlib     Crossref / S2
                        (受限 Python)      (可选 MathSciNet)
        |                  |
        +--------+---------+
                 v
        Verification Layer
          - 前提/条件审计
          - 数值 / 符号精确计算
          - Lean kernel 检查
          - NL ↔ Lean 题意对齐
          - （研究模式）文献事实 vs 猜想分栏
                 |
                 v
        带验证等级的最终回答（默认不展示教材页码引用）


检索子流水线：

  Query
    → 数学概念扩展（规则桥接表 + LLM）
    → Hybrid retrieval（FTS + vector + 结构化通道）
    → RRF + block_type 加权 + 依赖边加分 + 可选 rerank
    → relevant definition / theorem / proof / paper


模式：
  Teach / Solve（hint · socratic · full）
  Research（五段分栏 + 结构校验）
  Formalize（statement 确认 → 编译）

4. 刻意不做 / 真正的下一步
================================================================================

刻意不做：
  - 不拆多 Agent；不微调；不做无沙箱任意代码
  - 不宣称 Lean 验证了整段自然语言
  - citation graph 等 papers 语料
  - MathSciNet（许可/接口门槛）

下一步：
  1) 对被跳过扫描书做 OCR 质量核对后解禁入库
  2) 对已入库文档跑 `python -m app.dependencies` 批量抽依赖边
  3) 积累初等数论 Lean 样例
  4) 真实使用中收紧 Research 分栏的内容级校验（不仅标题）
